**Rewrite It In**

Игра для платформы Arduboy в жанре аркада.

Суть: мы играем за один из языков программирования. Уровень представляет собой поле с проектами, энергетиками и противниками. В рандомных местах появляется иконка одного из проектов, который нужно переписать. Кроме играбельного языка, есть боты, которые тоже устремляются к проекту, чтобы переписать его. Нужно успеть первым. Также рандомно на поле появляется энергетики, которые дают возможность увеличить на время свою скорость. За уровень нужно успеть переписать заданное число проектов. С каждым левелом увеличивается скорость противников/их количество/лимит проектов. За каждый проект начисляется количество очков. В конце игры высвечивается набранное число, а в меню можно отдельной опцией посмотреть предыдущие результаты, если они попали в топ.
